# 🌄 PeakPath

A simple trekking guide website. Pick your starting city (or use your live location) and find treks near you, with distance, weather, best season, what to carry, and Google Maps directions.

## Features
- 32 treks around Bengaluru, Mysuru, Mangaluru, Chennai, Hyderabad, Coimbatore, Kochi and Pune
- Use-my-location button and city selector, with nearest-first sorting
- Search, difficulty and distance filters
- Compare table and tick-off packing checklist
- Safety tips, About and Contact sections, dark mode support

## Run locally
Open `index.html` in a browser. No install or build step is needed.

## Deploy on GitHub Pages
1. Create a new public repository on GitHub.
2. Upload all files from this folder (keep `index.html` at the top level).
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/` after a minute.

## Before publishing
- In `js/script.js`, replace `your-email@example.com` with your real email.
- Distances and conditions are approximate; check permits and weather before trekking.
